# 古诗文前端 Material 3 设计说明

日期：2026-11-03。用户已确认：全站蓝色 Material 3、浅深主题、自适应导航，完整改进搜索阅读、AI 对话和表单反馈。实施位置：当前 checkout 新建功能分支，保留全部现有修改。

## 目标与范围

将现有墨夜前端升级为一致、清晰、可用的 Material 3 网站。覆盖全部现有路由的视觉，包括登录、内容浏览、复习、诗坛、个人中心、反馈、公告和管理控制台；重点完善搜索→阅读→AI 的连续体验。保留收藏、诗集、典故、卡片导出、声景与现有管理功能。

## 统一设计

- Vue 3、TypeScript、Vue Router、Pinia、Element Plus 沿用当前安装版本；不引入新的 UI 框架或动画依赖。
- 默认浅色，主色 #0B57D0，浅色主色容器 #D3E3FD，页面 #F8FAFD，主文字 #1F1F1F。配套深色使用 #A8C7FA 主色和 #131314 页面底色。语义化 CSS 变量覆盖 primary/on-primary、surface/container/on-surface、outline、error 以及状态层。
- 界面使用已安装 Noto Sans SC；仅诗词正文和诗词卡片保留 Noto Serif SC。界面字重以 400/500 为主，避免大范围字距和低对比浅字。
- 间距采用 4/8px 节奏；控件胶囊圆角、卡片 24px、对话框 28px；诗词展示可采用更宽松的阅读间距。
- Hover、focus、press 都有反馈；操作目标不小于 44px，主要图标控件 48px。键盘焦点清晰可见。状态过渡约 100–150ms、浮层约 200ms、页面局部切换约 250–300ms；遵循 reduced-motion。
- 所有文字、按钮、输入、列表和浮层同时适配浅深色；Element Plus 变量映射到同一套 tokens，避免旧页面遗留深色硬编码。

## 导航与页面

- 桌面使用分组的固定侧栏，覆盖诗词、诗人、名句、复习、诗坛、AI、公告、个人中心、控制台。中屏可收窄；手机使用顶部 app bar 和可关闭的模态导航抽屉，不重复叠加两套主导航。
- 当前 AppNav 保留在各页面入口，内部升级为统一导航；App.vue 负责按路由建立整体内容间距，避免批量迁移每个页面的装配。
- 导航显示当前页面、复习徽标和账户操作。抽屉支持 Escape、焦点管理、遮罩关闭、导航后关闭。提供跳到主要内容的链接。
- 登录为独立居中面板；控制台保留现有分区和较高信息密度，采用统一颜色、形状、控件和可读字号。

## 搜索与阅读

- 搜索进入首屏；推荐诗作为适度高度的卡片，替换占满视口的装饰场景。保留随机推荐、热词、自动完成、朝代筛选和分页。
- 搜索框有真实 label，建议列表支持 ArrowUp/ArrowDown、Enter、Escape 和明确选中状态；中文输入法组合事件不提交搜索。
- 朝代是可按键操作的筛选 chips，诗词卡片是有效链接，分页是按钮或链接。
- 搜索、筛选、分页进入 URL query；返回列表恢复条件、数据和滚动位置；过时的建议和搜索请求不能覆盖新状态。
- 首次加载、刷新、成功无结果、请求失败分别展示；失败有就地重试，刷新保留成功数据。
- 诗词详情提供返回操作，收藏提交时避免重复点击，诗集选择区分加载与无诗集，浮层宽度不超过视口。典故支持点击和键盘，四项阅读操作可换行或收进更多菜单。
- 向 AI 传递诗词 title/id 作为可编辑的提示草稿，不自动发送请求或执行写操作。

## AI 对话

- 多行 composer，Enter 发送，Shift+Enter 换行，中文组合输入不误发；生成时允许编辑下一条草稿。
- 明确区分等待、工具处理中、输出中、用户停止、失败。停止按钮中止浏览器请求/接收，保留已输出内容；不声称终止后台模型计算。
- 错误留在对应轮次并支持重试；重试保持上下文，避免重复用户消息。结束/停止/异常清理 reader 与 AbortController。
- 用户在底部时跟随输出；阅读旧消息时停止强制滚动，显示“查看最新回复”。
- 桌面历史侧面板、手机历史抽屉；历史加载、无会话、失败与重试分开显示。来源、反馈和可编辑发帖草稿保留。
- 保留 /agent/workflow、token header、sessionId、现有 meta/trace/tool_status/token/action/done SSE 与 API 契约；不修改 Java/Python 后端。

## 表单与其余页面

- 登录、注册、诗坛发布、个人资料及反馈表单提供字段错误、明确提交中状态和可恢复草稿；成功/失败通知由一个请求层级负责，避免重复提示。
- 用户界面的 card、tabs、列表、空状态与弹窗用统一 tokens；控制台与内容管理覆盖旧硬编码背景和反色文字，保留所有管理动作。
- 操作成功仅在确认服务响应成功后显示；不伪造业务数据、会话、登录或写操作。
